# 06. Drivers arquitectónicos

| ID | Driver | Descripción |
|---|---|---|
| DA01 | Disponibilidad | Operar sin interrupciones durante la campaña de matrícula y la jornada escolar. |
| DA02 | Rendimiento y concurrencia | Atender muchas solicitudes simultáneas de matrícula y registrar asistencia rápidamente. |
| DA03 | Seguridad y privacidad | Proteger datos de menores, cuentas y funciones administrativas. |
| DA04 | Integridad de datos | Garantizar matrícula única por año y respetar el límite de vacantes. |
| DA05 | Integración | Integrarse con servicios de notificación y exportar datos a SIAGIE. |
| DA06 | Usabilidad | Ofrecer flujos simples para apoderados, docentes y secretaría. |
| DA07 | Escalabilidad | Soportar crecimiento de estudiantes, secciones y años de historial. |
| DA08 | Mantenibilidad | Facilitar cambios y nuevas funcionalidades. |
