# Sistema Web de Gestión de Matrícula y Asistencia para el Colegio Miraflores

Proyecto de arquitectura de software para gestionar de forma digital la matrícula de estudiantes y el control de asistencia diaria del Colegio Miraflores, con comunicación oportuna hacia los apoderados.
